# Reverso (VST3)
Reverse-buffer effect for FL Studio and any VST3 host. Tempo-synced backwards audio with crossfaded grains,
feedback, low/high cut, diffusion, width and output gain.

Build: push to GitHub; Actions produces Reverso-Setup.exe (download the "Reverso-Windows" artifact).
Install: run Reverso-Setup.exe, then in FL Studio: Options > Manage plugins > Find installed plugins.
